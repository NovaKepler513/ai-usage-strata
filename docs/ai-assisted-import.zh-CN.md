# 用自己的 AI 整理账本

AI Usage Strata 提供两条 AI 协助路径，但两条都不会把这个网站连接到
Codex、Claude、ChatGPT 或任何其他服务。没有 API Key、账号绑定、云端同步，
也没有后台读取。

## 路径一：请 AI 整理成账本

这是大多数人最适合的默认路径。

1. 在页面点“让 AI 整理”。
2. 选择自己使用的 AI，复制或下载任务说明。
3. 明确告诉 AI：它可以读取哪些文件、导出记录或笔记。
4. 让它生成 `ai-usage-ledger.json`。
5. 将文件导入页面；先核对日期范围、总量、分类和估算记录，再看图表。

如果用的是 Cloud／网页端 AI，只上传或粘贴你愿意交出的资料。Cloud AI 不会、
也不应自动看到你电脑上的本地文件。

## 路径二：让本地编程 AI 只写一份文件

这条路径适用于已经在你指定目录中工作的本地 Codex 或 Claude Code。

1. 将下载的 `AI_USAGE_STRATA.md` 放入需要整理的目录，或把其中的任务贴进 AI 对话。
2. 指出它可以查看哪些子目录或导出文件。
3. 要求它写入前先给出资料范围摘要。
4. 只允许它创建或更新该目录里的 `ai-usage-ledger.json`。
5. 将生成的文件导入页面。

网站不会授予这项权限。AI 能读写什么，完全由你给它的本地权限和确认决定。
任务说明会要求它覆盖旧账本前先保留一份 `.bak` 备份。

## 一条不能省的记录规则

AI 可以降低整理难度，但不能把推测写成事实。

| 原始资料里有什么 | 账本必须怎么写 |
| --- | --- |
| 明确的时长或次数 | `"confidence": "recorded"` |
| 根据多条线索反推的数字 | `"confidence": "estimated"`，并写 `estimate_basis` |
| 那天没有可靠线索 | 留空，不要造一条记录 |

不要把原始对话、密钥、客户姓名、私密路径或个人身份信息放进证据标签。用一句短说明即可，例如：`"Codex 会话导出：产品简报"`。

## 页面会检查什么

每条导入记录至少需要有效日期和非负小时数；估算记录必须写 `estimate_basis`。
JSON、CSV、TSV 都会先在本机核对，浏览器确认后才会保存副本。完整字段见[账本格式](ledger-format.md)和[隐私说明](privacy.md)。
