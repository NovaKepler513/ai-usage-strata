# Interface languages

AI Usage Strata ships in 简体中文 and English. The language switch is local to
the browser and applies to the report and its evidence pages.

## Adding interface copy

Put user-facing UI text in `assets/i18n.js`, with a `zh` and an `en` entry.
Use the shared `t("key")` helper in `assets/app.js`, `assets/evidence.js`, and
`assets/public-adapter.js`. Do not expose schema names such as `confidence` or
`estimate_basis` in the interface; those belong in the developer field guide.
Standard demo categories use the `category(name)` helper as well. Translate
known categories such as `Research` and `Product`; leave a user's unfamiliar
category name unchanged rather than inventing a translation.

## Before release

Open both languages, including the evidence page and a failed import. Check
that numbers use the appropriate compact notation, date axes remain readable,
and a change of language does not alter the imported ledger.
