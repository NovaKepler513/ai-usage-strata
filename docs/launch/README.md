# v1.0.0 stable launch kit

This is the public launch kit for AI Usage Strata. It contains only a fictional product view and abstract artwork; do not replace those files with a real ledger, an evidence URL, a client name, or a local path.

## Files

| File | Use |
| --- | --- |
| `visuals/ai-usage-strata-cover-horizontal.png` | 1600×900 banner for a release page, LinkedIn, X, newsletter, or article header. |
| `visuals/ai-usage-strata-cover-vertical.png` | 1080×1440 portrait cover for short-form social posts. |
| `visuals/ai-usage-strata-product.png` | Screenshot of the real public app with its fictional example; use it after a cover to show the product is real. |
| `launch-copy.md` | Ready-to-edit English launch copy and a short release note. |

The ridge backgrounds were created with the built-in image-generation tool. All typography is rendered by the editable HTML cover sources, so the copy remains inspectable and easy to localise.

## A safe release post

1. Publish the v1.0.0 GitHub Release and live-app URL first.
2. Use a cover followed by the public product screenshot.
3. Pin the live app, source repository, and MIT License links in the reply or comments.
4. Never post a real ledger, source export, chat log, named client, or local evidence screen.

See [the Chinese release kit](README.zh-CN.md) for Chinese social-platform copy.
