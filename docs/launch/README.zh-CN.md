# v1.0.0 稳定版发布素材包

这套素材用于公开介绍 AI Usage Strata v1.0.0。产品截图只展示虚构案例；不要把任何真实账本、证据链接、项目名称或本地路径放进公开图文。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `visuals/ai-usage-strata-cover-horizontal.png` | 1600×900 横版主视觉；适合公众号头图、GitHub Release、LinkedIn、微博配图。 |
| `visuals/ai-usage-strata-cover-vertical.png` | 1080×1440 竖版封面；适合小红书首图、朋友圈长图、视频封面。 |
| `visuals/ai-usage-strata-product.png` | 真实公开版页面截图；适合放在第二张，说明这不是概念图。 |
| `发布文案.md` | 可直接复制的稳定版文案、不同平台短文案与发布顺序。 |

封面中的山脊背景由内置图像生成工具生成；标题文字和信息排版由本仓库中的 HTML 保证可编辑、可核对。`cover-horizontal.html` 与 `cover-vertical.html` 是两张成图的可编辑源文件。

## 最稳的发布顺序

1. 先发 v1.0.0 GitHub Release 和在线页面链接。
2. 用竖版封面 + 产品截图发小红书或朋友圈；正文放“本机保存、无账号、示例默认关闭”三个事实。
3. 用横版封面 + GitHub 链接发公众号、微博或 LinkedIn。
4. 评论区置顶在线体验、GitHub、MIT License 三个链接。
5. 不把真实账本、客户名、原始会话和本地证据页截图公开。
