## 这次已经交付什么

- 视觉更新：横版与竖版海报改为抽象的时间切片，用半透明层、等高线与错位切面表达“时间地层”，不再使用纸艺、水墨或写实地貌。
- 公开页面：中英文、本机优先、默认空账本、虚构示例按需加载。
- 开源入口：页面右下角蝴蝶圆标打开“版权与开源”，可下载 MIT License、访问源码、到 GitHub 反馈或贡献。
- 文档：双语 README、数据格式、AI 整理与安全边界、贡献说明、发布检查清单。
- 发布素材：横版主视觉、竖版封面、真实公开版截图和各平台首发文案。

## 下载包里怎么用

1. `03_横版主视觉.png` 用于公众号头图、GitHub Release、LinkedIn、微博配图。
2. `04_竖版社媒封面.png` 用于小红书首图、朋友圈长图或视频封面。
3. `05_公开版产品截图.png` 放在封面后，说明产品的真实首开状态。
4. `01_发布文案.md` 按平台复制；发出前只需确认标题和自己的发布语气。

## 公开时必须守住的边界

- 只发这套虚构示例截图和抽象视觉，不发真实账本、证据页面、聊天、客户信息或本机路径。
- 产品不读取用户电脑，也不替用户连接 Codex、Claude 或其他 AI；“让 AI 整理”是用户把一份任务说明交给自己选择的 AI。
- 公开反馈和 Pull Request 中不放真实导出文件、截图或个人资料。
