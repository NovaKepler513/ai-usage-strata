# AI Usage Strata 本地写入任务

当本地 Codex 或 Claude Code 帮用户整理 AI Usage Strata 账本时，使用本说明。
用户必须明确指出允许读取的目录或导出文件。

## 读取边界

- 只读取用户明确授权的目录、文件或导出记录。
- 不读取浏览器资料、隐藏缓存、密钥、登录态、无关目录或网络服务。
- 除非用户另行明确要求，否则不向任何远程服务发送资料。
- 读取前先列出资料范围；范围不清楚时提问，不能扩大扫描。

## 写入边界

- 只在当前目录写入 `ai-usage-ledger.json`。
- 如文件已存在，先在旁边创建 `ai-usage-ledger.json.bak`。
- 不修改原始日志、会话导出或其他项目文件。

## 账本规则

- 按自然日整理已授权资料。
- 只有来源里直接出现的数字，才用 `confidence: "recorded"`。
- 反推的数字必须用 `confidence: "estimated"`，并写清 `estimate_basis`。
- 没有证据的日期不写记录。
- `evidence.label` 只留简短且不敏感的说明，不能复制原始对话、密钥、客户名称或私密路径。
- 最后报告资料范围、记录数、日期范围、已记录总量和估算总量。

字段格式见 `../../docs/ledger-format.md`。用户会在浏览器中检查并导入 JSON；不要上传它。
